Petunjuk singkat

  1. Buka tombol Tautkan Perangkat — popup akan membuka https://web.whatsapp.com.
  2. Scan QR di popup dengan WhatsApp mobile (atau login via perangkat lain).
  3. Jika sudah, kembali ke halaman ini lalu tekan Saya sudah menautkan.
  4. Jika tidak menekan, popup akan otomatis menutup setelah 79 detik.
